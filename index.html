About ND Chat

Verified Zero-Knowledge

ND Chat

v3.1.0-release Build 2026.09 By NKD
ND Chat is a next-generation, decentralized private messaging application engineered for total anonymity and cryptographic sovereignty. It operates without phone numbers, emails, passwords, or centralized user tracking.
Core Privacy Guarantees
🛡️
Zero Server-Side Knowledge
Servers only relay encrypted ciphertext envelopes. Your private cryptographic keys never leave your browser sandbox.
⏱️
Ephemeral by Default
Messages exist only in local device memory and self-destruct automatically according to your timer. No permanent message archives exist on servers.
🔑
12-Word Sovereign Identity
Your identity is anchored by a 12-word BIP-39 recovery phrase with PBKDF2 (100,000 rounds) key derivation, allowing seamless multi-device login across phones, laptops, and desktops.
📞
Direct P2P Encrypted Audio
Voice calls connect directly peer-to-peer via WebRTC with Opus codec and DTLS-SRTP hardware-accelerated encryption.
Cryptographic Specifications
Key Agreement ECDH (NIST P-256 / secp256r1)
Symmetric Cipher AES-256-GCM (12-byte IV, 128-bit tag)
Recovery Mnemonic BIP-39 (2,048 Word English Dictionary)
Key Derivation (KDF) PBKDF2-HMAC-SHA256 (100,000 rounds)
Transport Protocol WebSocket Secure (WSS) + TLS 1.3
Audio Stream Protocol WebRTC (DTLS-SRTP, Opus Codec)
Local Key Storage IndexedDB (crypto_db, Origin Isolated)
Telemetry & Tracking 0% (Strictly Zero Data Collection)
Cross-Platform Readiness
Built on modern web standards (HTML5, Web Crypto API, WebRTC). Capable of running as a Progressive Web App (PWA) and deployable natively to Android/iOS (via Capacitor) and Windows/macOS/Linux (via Tauri or Electron).
